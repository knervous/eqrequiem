If nothing ever appears

  1. Click on this page, then press a face button on the controller. A stick nudge alone is often not enough.
  2. Plug the controller in with a USB cable. Chrome on macOS handles a wired Switch Pro Controller far more reliably than a Bluetooth one — this is the single most common fix.
  3. Try this same page in Safari. Safari reads controllers through the macOS Game Controller framework, so it often sees a Bluetooth pad that Chrome misses. If Safari sees it and Chrome doesn't, it's a Chrome limitation, not your controller.
  4. Re-pair the controller: hold the small Sync button next to the USB port until the lights run, then pair from macOS Bluetooth settings.
  5. Quit other apps that grab controllers (Steam, Parsec, controller remappers). Steam's Input layer in particular can claim the device exclusively so the browser never sees it.
